# Signed Note

Sign a text message with your digital signature. Like signing a letter, but cryptographically secure. Now with optional encryption for private messages.

{/* MARKER: what-is-this */}
## What is this?

Think of this like signing a paper document, but digital. When you sign a message:

- **Anyone can verify** it really came from you
- **No one can fake** your signature  
- **Any changes** to the message will break the signature

With encryption enabled:
- **Only the recipient** can read the message content
- **The signature** still proves it came from you
- **Double protection** - both authenticity and privacy

Try it below - type a message, optionally enable encryption, hit sign, and see how it works.

## How Digital Signatures Work

1. **You have a key pair**: A private key (secret) and public key (shareable)
2. **Signing**: Your private key creates a unique signature for your message
3. **Verifying**: Anyone with your public key can prove you signed it
4. **Tampering**: Change even one letter and the signature breaks

### With Encryption

When encryption is enabled:
1. **Message is encrypted** using the recipient's public encryption key
2. **Encrypted content is signed** with your private signing key
3. **Result is wrapped** in the signed note format
4. **Only the recipient** can decrypt and read the original message

### Why This Matters

Digital signatures are everywhere:
- Software updates (proving they're from the real company)
- Legal documents (digital contracts)
- Cryptocurrency (proving you own your coins)
- Email security (proving emails aren't spoofed)

Encryption adds privacy:
- Confidential communications
- Secure messaging
- Private document sharing
- Protected sensitive information

### The Format

Your signed message looks like this:

**Public message:**
```
~~~
Your message goes here
~~~
your-public-key-here
signature-goes-here
```

**Encrypted message:**
```
~~~
encrypted-content-here
~~~
your-public-key-here
signature-goes-here
```

Simple, readable, and cryptographically secure with optional privacy protection.
