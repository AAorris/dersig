## How it works

### Scoring System
- **Normal:** Score ≤ 1024 (Gray)
- **Magic:** Score > 1024 (Blue) 
- **Rare:** Score > 2048 (Yellow)
- **Legendary:** Score > 4096 (Orange)

### Features
- Real-time key generation
- Dictionary word matching
- Click any key to copy
- Best keys displayed first
